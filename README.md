# Jonathan — Portfólio Profissional

![Portfolio Preview](./assets/preview.png)

Portfólio profissional desenvolvido para apresentar minha trajetória, competências, projetos e experiências na área de tecnologia e desenvolvimento de soluções digitais.

O projeto foi pensado como uma experiência de apresentação profissional, funcionando simultaneamente como currículo online e portfólio de projetos.

## 👨‍💻 Sobre o projeto

Este projeto é meu portfólio pessoal desenvolvido com foco em:

- Apresentação profissional
- Projetos desenvolvidos
- Competências técnicas
- Experiências e formação
- Contacto profissional

A proposta é manter uma interface moderna, limpa e responsiva, permitindo que recrutadores, clientes e parceiros conheçam meu trabalho de forma rápida e objetiva.
